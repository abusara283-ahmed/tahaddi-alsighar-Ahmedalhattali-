# تحدي الصغار

ألعاب تعليمية للأطفال من ٣ إلى ٧ سنوات، تعمل دون إنترنت.

إعداد: أحمد الهطالي · Ahmed Alhattali

الرابط: https://abusara283-ahmed.github.io/tahaddi-alsighar-ahmedalhattali-/

## الجديد في الإصدار 2.1
- قسم القرآن الكريم: استمع واحفظ، سمّع السورة مع تصحيح آلي، أكمل الآية، الآية التالية (١٢ سورة من قصار السور بصوت الشيخ الحصري).

## الجديد في الإصدار 2.2
- واحة القرآن: جزء عمّ كاملًا مع الفاتحة (٣٨ سورة) بصوت الشيخ محمود خليل الحصري، والشيخ محمد صديق المنشاوي (المعلّم مع ترديد الأطفال)، مع إضاءة الآية وتكرار السورة للحفظ وتنزيل للرحلات.
- أناشيد بدون آلات موسيقية تعمل في الخلفية أثناء اللعب، مع إمكانية إضافة أناشيدك، ومؤقت للنوم.
